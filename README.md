# homebrew-tap

Official Homebrew tap for [Vacua](https://github.com/yuanweize/vacua) — explainable, safety-first storage intelligence for macOS.

## Installation

```bash
brew install yuanweize/tap/vacua
```

## Available Formulae

- `vacua`: Storage intelligence CLI for macOS (`vacua` + `vacua-intelligence`).
